# 来源与许可

- 本插件的 setup/CLI Skill 基于 [ZCode 插件市场的 `lark-cli`](https://github.com/zai-org/zcode-plugins/tree/0cc58d6/plugins/lark-cli) 改写，来源提交 `0cc58d6`，ZCode 仓库采用 Apache-2.0。原封装作者为 Z.ai。本插件由 PartMe.AI 维护，不是 Z.ai 官方发布。
- 被调用的 CLI 来源：[厂商项目](https://github.com/larksuite/cli)。本仓库不打包 CLI 二进制或凭证；厂商 CLI 的安装、版本与许可遵循其项目说明。
- 改写内容：独立插件目录、跨宿主 manifest、唯一 Skill 名称，以及去除依赖相邻 Skill 目录的相对引用。

- 图标来源：[ZCode `lark-cli` 图标](https://github.com/zai-org/zcode-plugins/blob/0cc58d6/assets/lark-cli/icon.png)；ZCode 记录的原始来源：https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/84a9f036fe2b44f99b899fff4beeb963~tplv-jbbdkfciu3-image:512:512.image。图标属于对应品牌，按识别用途展示。
